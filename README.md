# VideoMAE CCTV Annotation Studio

Локальное высокопроизводительное веб-приложение для подготовки данных и разметки видеозаписей под задачу бинарной классификации поведения: **«Shoplifting» (Кража/Сокрытие)** против **«Normal» (Обычное поведение)** для обучения моделей **VideoMAE v2**.

---

## Возможности

1. **Вкладка 1: Предобработка (Preprocessing & Extraction)**
   - Автономный декодер на **Python 3** с библиотекой **Decord** (`from decord import VideoReader, cpu`).
   - Идеальная обработка Variable Frame Rate (VFR) и искаженных метаданных CCTV.
   - Фиксация точных физических миллисекунд (PTS) в именах файлов: `frame_000142_ms00005680.jpg`.
   - Ограничение разрешения: `720p` (max 1280px), `1080p` (max 1920px), `Original` с пропорциональным сохранением aspect ratio.
   - Поддержка форматов `JPEG` (качество 90) и `WebP` (качество 85).
   - Стриминг прогресса в реальном времени в UI (Server-Sent Events) и окно терминала с логами.

2. **Вкладка 2: Студия разметки (Annotation Studio)**
   - Навигация по видео в сайдбаре с бейджами разметки (`Размечено` / `Не размечено`).
   - Быстрый вьюпорт на `<canvas>` без мерцания с кэшированием и предзагрузкой скользящего окна кадров.
   - Принудительная очистка памяти при переключении между видео (Garbage Collection).
   - Интерактивный таймлайн с эластичной плашкой:
     - Длина по умолчанию: ровно **3.0 секунды**.
     - Эластичные границы: регулировка от **2.0 до 5.0 секунд**.
     - Drag & Drop перемещение по таймлайну.
     - Поддержка нескольких непересекающихся плашек на одно видео.
   - **Loop Range**: воспроизведение интервала в цикле по реальным таймкодам `ms`.
   - Автосохранение в `annotations.json` по согласованной схеме.

## Горячие клавиши (Hotkeys)

| Клавиша | Действие |
|---|---|
| `Space` | Включить / Выключить зацикленный Loop активного интервала |
| `A` / `D` | Шаг на -1 / +1 кадр (микроподгонка) |
| `Shift + A` / `Shift + D` | Шаг на -10 / +10 кадров |
| `1` | Присвоить интервалу класс **Normal** (Зеленый) |
| `2` | Присвоить интервалу класс **Shoplifting** (Красный) |
| `Delete` / `Backspace` | Удалить активный интервал |
| `W` (или `Ctrl + →`) | Сохранить и перейти к следующему видео |
| `Q` (или `Ctrl + ←`) | Перейти к предыдущему видео |

## Установка и запуск

### Быстрый запуск:
- **Windows**: Запустите `setup.bat` (автоматически создаст `.venv`, установит pip-пакеты и `npm install`), затем для запуска используйте `start.bat`.
- **Linux / macOS**: Выполните `chmod +x setup.sh start.sh && ./setup.sh`, затем `./start.sh`.

---

### Ручная установка:

#### 1. Виртуальное окружение Python (создается в `.venv`)

**PowerShell (Windows):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**CMD (Windows):**
```cmd
.\.venv\Scripts\activate.bat
```

**Bash (Linux / macOS):**
```bash
source .venv/bin/activate
```

Установка/обновление зависимостей при необходимости:
```bash
pip install -r scripts/requirements.txt
```

> **Примечание:** Веб-приложение Next.js автоматически находит интерпретатор `.venv\Scripts\python.exe` без необходимости активировать его вручную перед запуском `npm run dev`.

### 2. Установка зависимостей Node.js
```bash
npm install
```

### 3. Запуск веб-приложения
```bash
npm run dev
```
Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).
